# CloudNest Web 页面 Demo

采用 React、TypeScript、Vite、Ant Design 和 Lucide 图标。默认进入本地 Demo，可体验文件浏览、整理和传输交互。另有一个可选的 API 模式，用于真实登录、查看本人资料和只读浏览目录。

## 启动

在项目根目录执行：

~~~powershell
pnpm --dir apps/web install
pnpm --dir apps/web dev
~~~

浏览器访问 [http://127.0.0.1:5173](http://127.0.0.1:5173)。开发服务器只监听本机，使用固定端口；端口占用时直接报错，不会自动切换。

构建检查：

~~~powershell
pnpm --dir apps/web build
~~~

## 真实登录模式

设置 API 模式后，Vite 将同源 `/api` 转发到 `CLOUDNEST_WEB_API_TARGET`，其默认地址为 `http://127.0.0.1:18081`。本地后端的 `CLOUDNEST_ALLOWED_ORIGINS` 需要包含实际的 Vite 来源。

~~~powershell
$env:VITE_CLOUDNEST_DATA_MODE = 'api'
$env:CLOUDNEST_WEB_API_TARGET = 'http://127.0.0.1:18081'
pnpm --dir apps/web dev
~~~

使用本地测试账号登录后，页面会调用 `GET /api/v1/me` 取得显示名称、用户名和配额。Access Token 保存在内存中，浏览器自行管理后端交付的 HttpOnly 刷新 Cookie。重载时，页面先调用 `POST /api/v1/auth/refresh`，成功后用新的 Access Token 读取本人资料。缺少有效会话时显示登录页。[隔离验收与复验命令](../../docs/开发学习记录.md#第-509-步恢复-web-重载后的会话与本人资料)

拿到本人资料后，页面使用其中的 `root_entry_id` 读取根目录，显示条目名称、类型和文件大小。点击文件夹进入子目录，点击目录路径中的上级名称可以返回。列表支持加载更多，空目录会显示提示，读取失败可重试当前页。页面重载恢复会话后从根目录开始。[目录浏览隔离验收](../../docs/开发学习记录.md#第-511-步接通-web-子目录只读浏览)

目录 GET 返回 `401 TOKEN_EXPIRED` 时，页面用现有刷新 Cookie 换取新令牌，按原目录 ID 和游标重试一次。刷新失败或重试仍被认证拒绝时，页面清理内存会话并回到登录。[令牌过期复验](../../docs/开发学习记录.md#第-512-步接通-web-目录读取过期刷新与单次重试)

## 可以体验的操作

- 我的文件、最近使用、我的收藏、传输列表、回收站导航。
- 文件夹层级浏览与面包屑、新建文件夹、重命名、移动；名称冲突和非法字符会给出提示。
- 全局文件名搜索、类型筛选、排序、列表/网格切换、复选与批量操作。
- 本地文件选择和拖拽添加，模拟传输进度、暂停、继续、取消。
- 示例图片和文档预览；本次选择的图片、文本以及浏览器支持的音视频可使用本地内容预览。
- 收藏、回收站删除、恢复、永久删除确认；回收目录时其后代从正常视图隐藏。
- 小屏折叠导航以及手机、平板、桌面布局。

## 演示边界

所有状态仅存于当前页面内存，刷新后恢复初始示例；左下角账号菜单也能重置体验。选择的文件不会上传到服务器，也不会写入数据库。

下载本次选择的文件会保存其真实内容；示例图片和文本可以下载。没有实际内容的 PDF、视频、设计稿等示例，下载时生成标注为“演示说明”的文本文件，避免将文本伪装成真实二进制文件。示例预览不代表已实现真实 PDF/Office 转换。

登录鉴权、真实设备连接、分享链接、持久化存储和实际上传下载调度不属于本版原型。后续根据体验反馈确定界面，再单独实现这些能力。
